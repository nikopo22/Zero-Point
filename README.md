# Zero Point

**Zero Point** — это 2D-платформер, в котором вы управляете роботом, случайно провалившимся в недра старой фабрики. Чтобы выбраться обратно на конвейер, герою предстоит преодолеть множество препятствий и использовать уникальные особенности своего корпуса.

---

## 🎮 Геймплей

Игрок проходит три уровня фабрики, поднимаясь после каждого на ярус выше. На пути встречаются  шипы, платформы и скрытые участки, которые требуют внимательности и правильного использования способностей робота.

---

## 🧠 Основные механики

### Базовое управление
- Движение влево/вправо
- Прыжок

### Уникальные способности
- **Режим магнита** — временное прилипание к вертикальным поверхностям, покрытым машинным маслом.
- **Сканирование окружения** — подсвечивает скрытые платформы на 2 секунды.

---

## ⚙️ Управление

| Действие | Клавиша |
|----------|---------|
| Движение влево / вправо | `A` / `D` |
| Прыжок | `W` |
| Режим магнита (зажать) | `Left Shift` |
| Сканирование окружения | `E` |
| Выход из игры | `Esc` |

## 🗂️ Структура проекта

- `Game1.cs` — основной игровой цикл, обновление состояний и отрисовка игры.
- `Player.cs` — логика управления персонажем, движение и способности.
- `Level.cs` — загрузка и хранение структуры уровня.
- `CollisionManager.cs` — обработка столкновений объектов и физики.
- `QuadTree.cs` — пространственное разбиение для оптимизации коллизий.
- `Camera.cs` — система камеры и следование за игроком.
- `Animation.cs` — управление анимациями через sprite sheet.
- `GameStateManager.cs` — переключение состояний игры (Menu, Playing, Pause, Win).
- `InputController.cs` — обработка ввода с клавиатуры.
- `Platform.cs` — платформы и статические объекты уровня.
- `Trap.cs` — ловушки и объекты, наносящие урон игроку.
- `HiddenPlatform.cs` — скрытые платформы, открывающиеся через способности.
- `MagnetAbility.cs` — механика магнита и взаимодействие с объектами.
- `ScannerAbility.cs` — механика сканирования скрытых объектов.
- `UIManager.cs` — пользовательский интерфейс и игровые экраны.
- `TextureManager.cs` — загрузка и хранение текстур и ресурсов.
- `SoundManager.cs` — управление звуками и музыкой.
- `Observer.cs` — реализация паттерна Observer через события C#.

## 🛠️ Сборка и запуск

### Требования

* Установленный **.NET 8 SDK**
* MonoGame Framework 3.8
* Операционная система: **Windows / macOS / Linux**
* Видеокарта с поддержкой OpenGL

### Установка MonoGame

Установить шаблоны MonoGame:

```bash
dotnet new install MonoGame.Templates.CSharp
```

### Команды для сборки

```bash
dotnet restore
dotnet build
```

### Запуск проекта

```bash
dotnet run
```
